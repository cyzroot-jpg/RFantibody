迁移方法
更新时间：2026-07-08 09:37:06
本文主要介绍单卡训练及分布训练场景下的模型手动迁移方法。

迁移约束
模型的迁移约束，可参考迁移约束。

单卡训练迁移
单卡训练场景，即PyTorch原始模型脚本使用单卡（对应太初的单个SDAA计算设备）进行训练的场景。

迁移流程
单卡训练场景的迁移流程如下图所示：



图1 单卡训练模型迁移流程

步骤一：导入torch_sdaa模块
在原始模型训练脚本中，导入torch_sdaa模块。

import torch
import torch_sdaa
步骤二：切换模型训练的设备
在原始模型训练脚本中，指定SDAA作为训练设备。

# 修改前，使用CUDA作为训练设备：
# device = torch.device('cuda')

# 修改后，使用SDAA作为训练设备：
device = torch.device('sdaa')
步骤三：替换PyTorch框架接口
将原始模型训练脚本中的所有torch.cuda接口替换为torch.sdaa接口。TecoPyTorch的SDAA接口与开源PyTorch的CUDA接口一一对应，只需将原始模型中相关API的cuda字样改为sdaa即可。

说明： 
TecoPyTorch与PyTorch框架接口的详细对应关系，请参考TecoPyTorch与PyTorch CUDA的功能性API比对。

以torch.cuda.is_available()和torch.cuda.device_count()为例，替换方法如下：

# 修改前的CUDA接口:
# torch.cuda.is_available()

# 改为SDAA接口：
torch.sdaa.is_available()

# 修改前的CUDA接口：
# torch.cuda.device_count()

# 修改后CUDA接口：
torch.sdaa.device_count()
将原始模型训练脚本中的模型、损失函数、数据集等对象的加载设备由cuda改为sdaa。示例如下：

# 修改前，模型加载到CUDA：
# model.to('cuda')

# 修改为模型加载到SDAA：
model.to('sdaa')

# 修改前，损失函数加载到CUDA：
# criterion = nn.CrossEntropyLoss()
# criterion.to('cuda')

# 修改为损失函数加载到SDAA：
criterion = nn.CrossEntropyLoss()
criterion.to('sdaa')

# 修改前，数据集加载到CUDA：
# images.to('cuda', non_blocking=True)
# target = target.to('cuda', non_blocking=True)

# 修改为数据集加载到SDAA:
images.to('sdaa', non_blocking=True)
target = target.to('sdaa', non_blocking=True)
替换Tensor创建接口。如果原始模型训练脚本中包含创建指定数据类型的Tensor接口，需要将接口的中device参数的值由cuda改为sdaa。

替换示例如下：

# 修改前：
# torch.tensor([1,2,3],dtype=torch.long,device='cuda')

（可选）步骤四：切换输入数据的数据格式
为了提高模型训练的性能，建议您在模型迁移的过程中，修改输入数据的数据格式为NHWC。示例如下：

for batch_idx, (data, target) in enumerate(train_loader):
    data = data.to(device) # 数据拷贝到设备上
    target = target.to(device) # 数据拷贝到设备上
    data = data.to(memory_format=torch.channels_last) # 数据格式转换为NHWC（channels_last）
（推荐）步骤五：开启自动混合精度AMP
建议您在模型中开启AMP。针对float16类型的卷积和矩阵乘法的运算，太初AI加速卡在软件层次进行了深度优化，使用AMP计算可以极大提升性能。

提示： 
针对卷积计算，太初当前软件栈仅存在float16类型的实现。所以在存在卷积计算的模型中，即使不使用autocast，也需要添加`GradScaler`相关代码，避免float16类型出现数值溢出导致精度下降的问题。

开启AMP的示例代码如下：

...
from torch.sdaa import amp              # 导入AMP
scaler = torch.sdaa.amp.GradScaler()    # 定义GradScaler
...
for epoch in range(epochs):
    for imgs, labels in train_dataloader:
        imgs, labels = imgs.to(device).to(memory_format=torch.channels_last), labels.to(device) 
        with torch.sdaa.amp.autocast():   # 开启AMP环境
            outputs = model(imgs)    
            loss = loss_func(outputs, labels) 
        optimizer.zero_grad()
        scaler.scale(loss).backward()    # loss缩放并反向转播
        scaler.step(optimizer)    # 参数更新
        scaler.update()    # 基于动态Loss Scale更新loss_scaling系数
（推荐）步骤六：开启分布式训练DDP
建议您在模型中开启分布式训练DDP，使用多个SDAA计算设备进行训练，以提升模型训练效。

以torchrun为例，开启DDP的示例代码如下：

说明： 
更多DDP的启动方法，请参考分布式训练示例。

...
# 导入DDP所需的依赖库
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
# # 设置IP:PORT，框架启动TCP Store为ProcessGroup服务
os.environ['MASTER_ADDR'] = 'localhost' # 设置IP
# 从外部获取local_rank参数
local_rank = int(os.environ.get("LOCAL_RANK", -1))

def main():
    # DDP backend初始化
    # rank号和device一一对应，进行set device
    # 需要在初始化ProcessGroup之前进行set device，tccl限制
    device = torch.device(f"sdaa:{local_rank}")
    torch.sdaa.set_device(device)
    # 初始化ProcessGroup，通信后端选择tccl
    torch.distributed.init_process_group(backend="tccl", init_method="env://")
    ...
    ddp_model = DDP(model) # DDP model
    ...
分布式训练迁移
分布式训练场景，即PyTorch原始模型脚本开启了DDP分布式训练的场景。

说明： 
与单卡训练场景的模型迁移相比，分布式场景下的模型迁移，需要在单卡训练迁移的基础上，指定分布式训练的计算设备和通信后端。
