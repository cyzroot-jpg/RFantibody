# 快速开始

本文覆盖 Codex、Cursor、Claude Code 三种入口。三者共用同一套 `ops/` skills 和主指令；Codex / Cursor 读取 `AGENTS.md`，Claude Code 读取 `CLAUDE.md -> AGENTS.md`。

## 通用前置

```bash
cd teco-ops-agent
chmod +x init.sh
test -d ../../teco-ops
```

基础依赖：

- Python 3.8+
- 已配置本机 LLM 凭据
- 需要在线文档检索时，需内网/VPN 可访问 `docs.tecorigin.net`

## Codex

```bash
./init.sh project codex
codex
```

安装结果：

| 路径 | 内容 |
|------|------|
| `.codex/skills/*` | 指向 `ops/` 下各 skill 的符号链接 |
| `.codex/config.toml` | 项目级 hooks 配置，写新算子或优化 kernel 前提示读取性能最佳实践入口、learned-patterns 和 code-style |
| `AGENTS.md` | 主 Agent 指令 |

首次打开仓库时，如果 Codex 提示 `Hooks need review`，需要确认允许执行 `.codex/config.toml` 中声明的 hook 命令；确认后，新算子前置检索 hook 才会运行。

可选在线文档 MCP：

```bash
cat configs/codex_mcp.example.toml >> ~/.codex/config.toml
```

如果已有 `~/.codex/config.toml`，建议手动合并其中的 `[mcp_servers.*]` 段落，避免覆盖个人配置。

## Cursor

```bash
./init.sh project cursor
```

然后在 Cursor 中打开本仓库。

安装结果：

| 路径 | 内容 |
|------|------|
| `.cursor/skills/*` | 指向 `ops/` 下各 skill 的符号链接 |
| `AGENTS.md` | 主 Agent 指令 |

## Claude Code

### init.sh 方式

```bash
./init.sh project claude
claude
```

安装结果：

| 路径 | 内容 |
|------|------|
| `.claude/skills/*` | 指向 `ops/` 下各 skill 的符号链接 |
| `.claude/settings.json` | 从 `configs/claude_settings.example.json` 写入或更新的项目 settings |
| `CLAUDE.md` | 指向 `AGENTS.md` 的软链接 |

全局安装：

```bash
./init.sh global claude
```

### Plugin 市场方式

在 Claude Code 会话中：

```text
/plugin marketplace add <本仓库 Git URL>
/plugin install teco-ops-agent-skills@teco-ops
```

Plugin 安装不会自动创建 `CLAUDE.md`。本仓库已跟踪 `CLAUDE.md -> AGENTS.md` 软链接；如果本地缺失，可在仓库根目录执行：

```bash
ln -sf AGENTS.md CLAUDE.md
```

市场定义见 `.claude-plugin/marketplace.json`，插件元数据见 `.claude-plugin/plugin.json`。

## LLM 配置

默认模型：`deepseek-v4-pro`。

| 工具 | 配置文件 | 模型字段 |
|------|----------|----------|
| Codex / `run_cli.py` | `~/.codex/config.toml` + `configs/llm_runtime.json` | `model` / `default_model` |
| Claude Code | `~/.claude/settings.json` 或 `.claude/settings.json` | `model` / `env.ANTHROPIC_MODEL` |
| Cursor | 由 Cursor 自身配置模型；本仓库只安装 skills 和 `AGENTS.md` |

`configs/llm_runtime.json` 是 `run_cli.py` / `teco_ops_agent` 的默认 LLM 运行时配置。`configs/codex_mcp.example.toml` 只作为 Codex MCP 示例，不自动生效。`configs/claude_settings.example.json` 由 `./init.sh project claude` 消费。

API Key 建议放在用户级配置中：

- Codex：`~/.codex/auth.json`
- Claude Code：`~/.claude/settings.json` 的 `env.ANTHROPIC_API_KEY` / `env.ANTHROPIC_AUTH_TOKEN`

不要把个人 API Key 写入仓库内配置文件。
