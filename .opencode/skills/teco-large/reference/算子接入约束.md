# tecoops 算子接入约束（SDAA / T1）

赛事要求模型必须使用 `tecoops` 的三个算子：`flash_attn_varlen_func`、`reshape_and_cache`、`rms_norm`。
本文记录它们的接口、硬性约束、以及接入时踩过的坑。

---

## 1. flash_attn_varlen_func

**Python 绑定**（`api/torch_ext.cpp` / `tecoops._torch_ext`）：
```
tecoops.flash_attn_varlen_func(
    q, k, v,                     # q:[total_q, num_heads, head_size]
                                 # k/v:[num_blocks, num_kv_heads, block_size, head_size]
    max_seqlen_q, cu_seqlens_q,  # cu_seqlens_q: int32[batch+1]
    max_seqlen_k,
    cu_seqlens_k,                # 未使用，传 empty
    seqused_k,                   # int32[batch]
    softmax_scale,               # float
    causal,                      # bool（本实现要求 True）
    window_size,                 # int32 tensor[1]；<=0 关闭；>0 为“含当前 token 的窗口大小”
    block_table,                 # int32[batch, block_table_dim]
    return_softmax_lse,          # False
    out)                         # 原地写出
```

**硬性约束**
1. **KV 布局必须是 HND**：`[num_blocks, num_kv_heads, block_size, head_size]`。
   对应 `FlashAttentionBackend.get_kv_cache_shape()` 返回 `(2, num_blocks, num_kv_heads, block_size, head_size)`，
   `get_kv_cache_stride_order()` 返回 `(0,1,2,3,4)`。
2. **block_size 必须 = 32**（kernel 里 `BN=32`，`cur_block = j / block_size`）。
   `get_supported_kernel_block_sizes()` 返回 `[32]`、`get_preferred_block_size()` 返回 `32`。
3. **sliding window**：kernel 在 `apply_causal_mask` 内融合 causal + window 两道 mask
   （`first_allowed = rel_q_pos - window_size + 1`）。full 层传 `<=0`。
4. **softmax scale 必须透传**：kernel 默认用 `1/sqrt(head_dim)`；若模型 scaling != 该值
   （如 Gemma4 用 `1.0`），必须把 `softmax_scale` 传到 kernel（`args.softmax_scale = softmax_scale > 0 ? ... : 默认`）。
5. **SPM 容量约 256KB/SPE**：`BM*head_dim` 相关缓冲（qbuf/obuf/o_accum）随 head_dim 线性增长。
   `head_dim > 128` 需缩小 Q tile：
   ```
   BM = 128;  if (BK > 128) BM = 64;  if (BK > 256) BM = 32;
   ```
   （`M128_N32` matmul tile 允许 `M2<=128`，缩 BM 合法。）**不缩会出现“结果全错/NaN”的静默越界。**
6. GQA 支持（`num_kv_groups = local_head_num / local_kv_head_num`）。

**实现位置**（teco-ops）
- kernel：`teco/ual/kernel/flash_attention/flash_attention.scpp`
- args：`teco/ual/args/flash_attention_args.h`
- 接口：`teco/interface/ops/flash_attention.cpp`、`teco/interface/include/tecoops.h`
- 绑定：`api/torch_ext.cpp`
- modelzoo 封装：`tecovllm_models/layers/flash_attn.py`

**模型侧封装要点**
- `FlashAttentionImpl` 不要对 `sliding_window` 抛错，要存下来并转成 `window_size` 传入；
- window 传参用 1 元素 int32 tensor（保持底层 C 签名稳定）；
- 非连续 q/k/v 先 `.contiguous()`；
- 提供纯 torch 回退路径（`TECO_BASIC_FA=1`）用于快速定位“是模型问题还是 kernel 问题”。

## 2. rms_norm

```
tecoops.rms_norm(input_2d, weight, residual_or_None, out, residual_out_or_None, eps)
```
- 输入必须 2D `[num_tokens, hidden_size]`（其他维度在封装里 flatten/restore）；
- **weight 不能为 None**（内核要求非空）→ weight-less norm（如 Gemma4 的 V norm）传全 1 向量；
- 只支持 **fp16**（模型用 `--dtype float16`）；
- residual 融合：传入 residual + residual_out 即一步完成 add+norm。

**实现位置**：`teco/ual/kernel/rms_norm/rms_norm_fp16.scpp`、`teco/interface/ops/rms_norm.cpp`；
modelzoo：`tecovllm_models/layers/rms_norm.py`（`RMSNorm(..., has_weight=False)`）。

---

## 3. reshape_and_cache

```
tecoops.reshape_and_cache(key, value, slot_mapping, key_cache, value_cache)
```
- key/value：`[num_tokens, num_kv_heads, head_size]`（非连续先 `.contiguous()`）；
- cache：HND `[num_blocks, num_kv_heads, block_size, head_size]`；
- `slot_mapping`：int64 `[num_tokens]`，`-1` 跳过。

**实现位置**：`teco/ual/kernel/reshape_and_cache/reshape_and_cache_fp16.scpp`；
modelzoo：`tecovllm_models/layers/flash_attn.py::reshape_and_cache_flash`。

## 4. 编译与安装

```bash
source /opt/tecoai/setvars.sh
cd teco-ops-{队名}
WITH_TORCH=ON WITH_INFERENCE_PLUGIN=OFF python setup.py bdist_wheel
pip install dist/tecoops-0.0.0-cp312-cp312-linux_loongarch64.whl --force-reinstall
ls -la build/lib.*/tecoops/*.so    # 确认 .so 时间戳已更新（kernel 编进 libteco_ops.so）
```

> 只改 Python 封装（modelzoo：`tecovllm_models/layers/*.py`）时，因为是 `develop` 安装，无需重编译。
