# RFdiffusion 抗体样本偏差报告（SDAA vs A100）

> 现象：同一份代码、同一输入、同一随机种子，`RFdiffusion` 抗体设计在 SDAA 上与 H100 参考的**逐原子最大偏差达 2.75 / 10.76 Å**，而 A100 仅 **0.0595 / 0.7987 Å**。
> 结论：**这不是 SDAA 精度差或 bug，而是"SDAA 与 NVIDIA 算子舍入模式不同"，被 RFdiffusion 48 步扩散在敏感样本上放大。**

---

## 一、问题

| 样本（vs `H100_references`） | SDAA 逐原子最大偏差 | A100 逐原子最大偏差 | SDAA/A100 |
|------------------------------|---------------------|---------------------|-----------|
| RFdiffusion 抗体 `ab_des_1` | **2.75 Å** | 0.0595 Å | ~46× |
| RFdiffusion 抗体 `ab_des_0` | **10.76 Å** | 0.7987 Å | ~13× |
| RFdiffusion 纳米抗体 `nb_des_0/1` | 0.0168 / 0.0476 Å | 0.0133 / 0.1168 Å | ~1×（一致） |

- 抗体样本：SDAA 偏差远大于 A100；
- 纳米抗体样本：两者基本一致。

---

## 二、原因

### 2.1 同输入下，SDAA 与 NVIDIA 的算子"舍入模式"不同（直接实测）
用 `op_fingerprint.py`（同 seed → 同输入），**每个算子的 fp32 输出 SDAA ≠ A100**（末位不同），例如：

| 算子 | SDAA | A100 |
|------|------|------|
| Linear[0] | -1.697747111320e-01 | -1.697751283646e-01 |
| matmul[2] | -1.650602817535e+00 | -1.650608062744e+00 |
| softmax[0] | 7.741543813609e-04 | 7.741543231532e-04 |
| cdist[0] | 9.568318724632e-03 | 3.906250000000e-03 |

### 2.2 但两者"精度"相同（不差）
用 `op_diff_probe64.py`（以 **float64 真值**为基准）：

| 算子（rel_err vs fp64） | SDAA | A100 |
|-------------------------|------|------|
| Linear | 1.81e-7 | 2.26e-7 |
| matmul / einsum | 1.70e-7 | 1.61e-7 |
| LayerNorm | 1.13e-7 | 1.26e-7 |

→ 都 ~1e-7（= fp32 机器精度上限）；**SDAA 不比 A100 差**（`Linear` 上还略优）。

### 2.3 为什么 A100 很小、SDAA 很大
- **A100 与 H100 共用 cuBLAS/cuDNN** → 对同一输入**舍入几乎相同** → A100 的输出"紧跟"H100 → 偏差小（0.06–0.8 Å）；
- **SDAA 用不同的 kernel（TecoBLAS/TecoDNN）** → **舍入模式不同**（尽管同样"准"）→ 输出偏离更多；
- 再经 **RFdiffusion 的 48 步迭代**放大。

### 2.3.1 补充证据：x86 CPU 上也跑（偏差更大）
在另一平台（**x86 CPU**）跑同一脚本，偏差**比 SDAA 还大**：

| 样本（vs H100） | A100 | SDAA | **x86 CPU** |
|-----------------|------|------|-------------|
| `ab_des_0` 逐原子最大偏差 | 0.799 Å | 10.765 Å | **32.568 Å** |
| `ab_des_1` 逐原子最大偏差 | 0.060 Å | 2.755 Å | **3.959 Å** |

**排序：A100 ≪ SDAA < CPU**，与"离 H100 的数值距离"一致（x86 CPU 的 fp32 精度比 GPU 差，实测 ~3–4e-7 vs ~1e-7）。
→ **证明这不是 SDAA 特有问题**：任何非 H100 环境都会在敏感样本上偏，且偏差大小取决于"实现与 H100 差多远"。

### 2.3.2 偏差来自"对接姿态"，不是"折叠错误"
同一次 CPU 实验的分量分析（`ab_des_0`）：

| 分量 | SDAA | 说明 |
|------|------|------|
| 靶标链 T 最大偏差 | 0.233 Å | **靶标几乎不动** → 坐标准确、帧一致 |
| 全结构 CA RMSD（未叠合） | 5.749 Å | 大 |
| **binder 叠合后(形状)** | **0.960 Å** | 把 binder 对齐后**形状差仅 ~1 Å** |

→ 大偏差**主要是 binder 的"整体对接位置/朝向"不同（rigid-body pose）**，binder 自身折叠形状其实很接近（A100 0.175、SDAA 0.960、CPU 0.577 Å）。即**采样到另一个合法 dock**，**不是折坏了**。

### 2.4 为什么偏偏是"抗体"样本
RFdiffusion 是 48 步串行去噪（上一步输出喂下一步）：

| 维度 | 纳米抗体 | 抗体 |
|------|----------|------|
| 残基 / 链 / 设计环 | ~364 / 单链 / 3 | **478 / H+L 双链 / 6** |
| 轨迹性质 | **稳定**（差异收敛） | **敏感**（差异放大） |
| 结果 | 与参考一致 | 走到**另一个合法设计** |

**样本敏感度排序三平台一致**（`nb < ab_des_1 < ab_des_0`），且 **NVIDIA 内部 A4000↔H100 在 ab_des_0 上就已达 1.22 Å** → 说明是**样本固有敏感性**，非 SDAA 特有。

### 2.5 一句话
> **原因 =（SDAA 与 NVIDIA 的算子舍入模式不同）×（RFdiffusion 48 步扩散对敏感样本的非线性放大）；两者精度其实一样。不是精度差、不是 bug。**

---

## 三、为什么 `export TORCH_SDAA_ALIGN_NV_DEVICE=a100` 解决不了

**该变量只对齐"随机数发生器（RNG）"，而病因是"算子浮点计算"。**

1. 它只让 `torch.randn(device='sdaa')` 与 A100 一致，**改不了算子怎么算**；
2. 且 RFdiffusion 的随机性来自 **CPU 的 numpy / 无 device 的 torch**，该变量**根本碰不到**；
3. 实测：设置该变量后 RFdiffusion/ProteinMPNN 输出**逐字节不变** → 证明它对本问题**无效**。

> 类比：换了一模一样的食材（RNG 对齐），但灶不同（算子实现不同），菜还是不一样。

## 四、影响

| 方面 | 影响 | 说明 |
|------|------|------|
| **适配正确性** | **无影响** | 纳米抗体逐原子复现（0.017 Å）、RF2 分数与参考一致（0.90/10.67 vs 0.89/10.64）、图算子/SE(3)/权重 SDAA=CPU；且已修复真 bug（`nn.Embedding`） |
| **精度评测口径** | **有影响** | 跨设备"逐原子对齐 H100"不是合格线（连 A100↔H100 自身都差 0.8 Å）；应改用 **SDAA 专属参考** 或 **行为化指标** |
| **设计结果本身** | **基本无影响** | SDAA 得到的是**另一个合法设计**（结构合法、CDR 标注/序列一致），不是错误设计；扩散本就是生成式、多设计筛选 |
| **可复现性** | **跨设备位级复现不可能** | 同设备（SDAA）可复现（重跑逐字节相同）；跨设备只能保证"功能一致" |
| **性能/显存** | **无影响** | 与本问题无关 |

---

## 五、结论与建议

- **结论**：抗体样本的大偏差是"**跨实现舍入差异 + 扩散混沌放大**"，**不是精度缺陷、不是 bug**；A100 小是因为它与 H100 同源同舍入。
- **建议**：
  1. 用 **SDAA 专属参考**（`python -m test.run_tests --create-refs`）按官方同设备口径判精度；
  2. 或改用**行为化指标**（结构合法 / CDR 标注 / 原子数 / 序列 / RF2 分数区间）；
  3. `TORCH_SDAA_ALIGN_NV_DEVICE` 对本问题无效，**不必使用**；
  4. 若需对齐 NVIDIA：只能"减小算子差异"（统一 fp32、关键归约高精度、算子回落/反馈厂商），**无法位级一致**。

## 六、评测结果表与指标说明（SDAA vs CUDA）

### 6.1 评测结果

| 模型 | 数据集 | 指标 | 值（SDAA） | 值（CUDA） |
|------|--------|------|-----------|-----------|
| RFdiffusion | `rsv_site3.pdb` + `h-NbBCII10.pdb`（纳米抗体） | 逐原子最大偏差 | 0.0168 / 0.0476 Å | 0.0133 / 0.1168 Å |
| RFdiffusion | `rsv_site3.pdb` + `hu-4D5-8_Fv.pdb`（抗体） | 逐原子最大偏差 | 2.75 / 10.76 Å | 0.0595 / 0.7987 Å |
| ProteinMPNN | `ab_des_0.pdb` | 骨架坐标偏差 | 0.0000 Å | 0.0000 Å |
| ProteinMPNN | `ab_des_0.pdb` | 序列一致率 | 97.28% / 94.98% | 100.00% / 100.00% |
| RF2 | `ab_proteinmpnn_output.pdb` | pred_lddt | 0.90 | 0.90 |
| RF2 | `ab_proteinmpnn_output.pdb` | pae | 10.67 | 10.54 |
| RF2 | `ab_proteinmpnn_output.pdb` | interaction_pae | 19.47 | 19.21 |
| RF2 | `ab_proteinmpnn_output.pdb` | framework_aligned_antibody_rmsd | 1.17 Å | 1.21 Å |
| RF2 | `ab_proteinmpnn_output.pdb` | framework_aligned_cdr_rmsd | 2.10 Å | 2.15 Å |

### 6.2 指标含义与作用

**A. 结构一致性类（"输出 vs 参考" —— 看像不像标准答案）**

| 指标 | 含义 | 作用 / 方向 |
|------|------|-------------|
| **逐原子最大偏差** | 输出与参考**逐原子配对**求坐标距离，**取最大值**（Å）= 最差原子的偏移量 | 官方判定结构的核心指标：**≤0.1 Å**（RF2 ≤0.2 Å）才算通过；越小越好 |
| **骨架坐标偏差** | ProteinMPNN 输出骨架坐标 vs 参考的偏差（只改序列、不动骨架，应为 **0**） | 验证"序列设计没破坏骨架" |
| **序列一致率** | 与参考**残基名相同的位点比例**（%） | 验证"设计序列与参考是否一致"；越大越好 |

**B. RF2 打分（模型自评 —— 用于筛选设计）**

| 指标 | 含义 | 作用 / 方向 |
|------|------|-------------|
| **pred_lddt** | 预测结构**置信度**（0–1） | 越高越好 |
| **pae** | **预测对齐误差**（Å）：残基间相对位置的预期误差（整体）| 越低越好；过滤阈值 **pae < 10** |
| **interaction_pae** | 只算**抗体-靶标跨链界面**的 PAE | 越低越好；衡量界面可信度 |
| **framework_aligned_antibody_rmsd** | 用**框架**叠合后，**整条抗体**的 Cα RMSD（Å） | 越低越好；过滤阈值 **< 2 Å** |
| **framework_aligned_cdr_rmsd** | 同上，但只算 **CDR 环** | 越低越好 |

> `*_rmsd / pred_lddt / pae` 均为 **RF2 给每个设计打的自评分**；官方测试会再把这些值与参考按容差（相对 1% 或绝对 0.1）比对。`framework_aligned_` = 先按**框架**叠合再算（官方另有 `target_aligned_`，按**靶标**叠合）。

### 6.3 结果解读

| 结果 | 说明 |
|------|------|
| 纳米抗体（RFdiffusion）：两平台 ~0.01–0.12 Å | 与参考一致 → **适配正确** |
| **抗体（RFdiffusion）：SDAA 2.75/10.76 Å，远大于 CUDA 0.06/0.80 Å** | **跨设备舍入差异被扩散放大**（敏感样本），非精度缺陷、非 bug（见 §一~§五） |
| ProteinMPNN 骨架坐标：两平台均 0.0 Å | 骨架未被改动 ✅ |
| ProteinMPNN 序列：SDAA 97%/95%，CUDA 100% | 采样对数值敏感（少数位点翻转），差异小 |
| RF2 各项分数：两平台几乎一致（0.90 / 10.67 / 1.17 vs 0.90 / 10.54 / 1.21） | **RF2 稳定、适配正确** ✅ |
